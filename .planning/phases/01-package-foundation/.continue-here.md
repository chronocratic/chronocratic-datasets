## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| `src.rbspaper` imports | Copy-pasting rbspaper imports directly produces broken `src.rbspaper` prefixes instead of `tsdatasets` | advisory | All ported code must use clean `tsdatasets` imports; grep for `src\.rbspaper` after each phase |
| `pythonpath = [".", "src"]` redundancy | Adding `src` to pytest pythonpath with src-layout editable install causes duplicate module imports | advisory | Keep `pythonpath = ["."]` only; package is accessible via installed name |
