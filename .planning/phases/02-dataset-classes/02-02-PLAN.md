<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| dataset constructor -> stored data | User-provided numpy/pandas data stored as instance attributes; type validation needed |
| __getitem__ index -> _go_to_idx | Integer index from external caller (DataLoader) mapped to internal cursor |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-02-01 | Spoofing | FixedTimeSeriesDataset.__init__ | mitigate | Type-check data is np.ndarray or pd.DataFrame via isinstance; raise TypeError for unsupported types |
| T-02-02-02 | Spoofing | FixedTimeSeriesDataset.seq_len | mitigate | Validate data has at least 2 dimensions (shape[1] access); raise ValueError for 1D inputs |
| T-02-02-03 | Repudiation | FlexibleTimeSeriesDatasetSingleFile._go_to_idx | mitigate | Bounds check idx >= len(self) raises IndexError with message — inherited from rbspaper pattern |
| T-02-02-04 | Denial of Service | TimeSeriesDataset.__init__ mode dispatch | mitigate | _get_sample_fun_map lookup raises KeyError for invalid mode; mode is typed as TimeSeriesDatasetMode enum so only valid values accepted |
| T-02-02-05 | Injection | transformations_sequence | accept | Callables are user-provided but applied to isolated data; no external I/O or command execution in transform pipeline |
</threat_model>
