Current mixin uses three string-dispatch methods:
- _pick_the_encoder(): checks model_name to decide query_encoder vs _averaged_encoder
- _pick_eval_method(): checks model_name to decide feature_concatenation vs pooling
- _pick_slice(): checks model_name to decide None vs computed slice

CoST uses: query_encoder, feature_concatenation, None slice
TS2Vec/AutoTCL use: _averaged_encoder, pooling, computed slice

Approach: add three concrete strategy methods to each model class:
- _get_encoder() -> returns the encoder to use for inference
- _get_eval_method() -> returns the evaluation function reference
- _get_slice(sliding_padding, sliding_length) -> returns slice object
</context>

  def _get_encoder(self) -> Any:

  def _get_slice(self, sliding_padding: int, sliding_length: int) -> slice | None:
