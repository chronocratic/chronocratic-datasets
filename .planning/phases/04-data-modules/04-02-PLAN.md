    4. Call self._transform_data() (abstract — subclass implements).
    5. Scale time features if present, concatenate back.
    6. Call self._calculate_num_features().
    7. Call self._split_data().

    Abstract methods: _set_data_slices(), _transform_data().

    Properties: train_slice, valid_slice, test_slice, full_data, num_time_series_features.

    _post_prepare_data(): Call _set_data_slices().

    _split_data(): Slice _full_data using _train_slice, _valid_slice, _test_slice. Assign to _train_data_samples, _valid_data_samples, _test_data_samples.
