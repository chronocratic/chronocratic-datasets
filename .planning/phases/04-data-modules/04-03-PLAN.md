    1. Validate folder exists (D-16).
    2. Set _dataset_name from folder name.

    4. Read both files via _read_arff_data_file, process via _process_stacked_data.
    5. If MANUAL split: concatenate samples+labels, re-split with train_test_split (stratify on labels).
    6. Create validation split if valid_size > 0.0 (filter labels with count > 1, stratify with fallback).
    7. Apply _process_data_with_varying_sequence_lengths() from base.
    8. Convert labels to pd.Series (dtype='category').
    9. Compute _num_classes from unique labels, _seq_len and _num_features from first sample shape.

    train_dataloader/val_dataloader/test_dataloader: Use UEAClassificationMultivariateDataset (from Phase 2 datasets/uea.py). Call base _process_*_dataloader.
