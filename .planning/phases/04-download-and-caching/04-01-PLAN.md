    - Create `cache_dir` via `mkdir(parents=True, exist_ok=True)`
    - Set `destination = cache_dir / filename`
    - Cache hit check: if `destination.exists()` and NOT `overwrite_cache`:

      - If `sha256` is None, log info and return destination.
    - If `overwrite_cache` and file exists, unlink destination.

    - Open destination with `wb`, iterate `response.iter_content(chunk_size=_CHUNK_SIZE)`: write chunk, update hash, update progress bar
    - If `sha256` is not None: compare `hash_obj.hexdigest()` with expected. On mismatch, unlink destination, raise `ValueError(f"SHA256 mismatch for {url}: expected {sha256}, got {actual}")`
    - If `sha256` is None: log `logger.warning("No SHA256 checksum provided — skipping integrity verification for %s", filename)`
    - Return destination
    - Use `with` statements for context managers (session, file handle, tqdm)

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| External URLs -> download_file | Untrusted HTTP responses cross into local cache |
| Archive files -> extract_archive | Untrusted ZIP content crosses into extracted directory |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation |
|-----------|----------|-----------|-------------|------------|
| T-04-01 | Spoofing | download_file HTTP response | Mitigate | HTTPS-only URLs enforced by `DatasetConfig.validate_https_only()` (Phase 3). `requests` verifies TLS by default. |
| T-04-02 | Tampering | download_file cached file | Mitigate | SHA256 validation after download (`hash_obj.hexdigest()` comparison). Corrupted files deleted via `destination.unlink()`. |
| T-04-03 | Repudiation | download_file progress | Mitigate | Structured logging via `logger.info()` for download start/end, cache hits, and SHA256 results. |
| T-04-04 | Information Disclosure | _create_session retries | Accept | Retry logs HTTP status codes but not request bodies. Download URLs are public dataset sources. |
| T-04-05 | Denial of Service | download_file large files | Mitigate | Streaming download via `iter_content(chunk_size=32KB)` — memory usage bounded by chunk size, not file size. |
| T-04-06 | Elevation of Privilege | extract_archive zip-slip | Mitigate | `zipfile.ZipFile.extractall()` in Python 3.12 rejects absolute paths and `..` components by default (CVE-2007-4559 fix). |
</threat_model>
