## Objective

Add dataloader smoke tests (D-03) for WeatherModule and ElectricityLoadModule, verifying `prepare_data() -> setup('fit') -> train_dataloader()` returns DataLoader with correct batch shapes. Tests the fractional-split path (60/20/20) vs ETT's intrinsic 16/4/4.

## Purpose

WeatherModule (73%) and ElectricityLoadModule (88%) need integration coverage. Unlike ETT which uses absolute month-boundaries, these use fractional splits — a different code path. Smoke tests verify the full pipeline works end-to-end.

### Key Interfaces

From `src/tscollection/datasets/modules/weather.py`:
- `WeatherModule.__init__(*, dataset_file_path: Path, seq_len=128, mode, batch_size=32, ...)`
- `WeatherModule.prepare_data()` — reads standard CSV (`parse_dates=True, index_col='date'`); univariate uses `df.iloc[:, -1:]`
- `_set_data_slices()` — 60/20/20 fractional: `int(0.6 * N)`, `int(0.8 * N)`
- `_transform_data()` — `expand_dims(axis=0)`, produces shape `(1, samples, features)`

From `src/tscollection/datasets/modules/electricity.py`:
- `ElectricityLoadModule.__init__(*, dataset_file_path: Path, ...)`
- `ElectricityLoadModule.prepare_data()` — reads semicolon CSV (`sep=';', decimal=','`), resamples hourly, filters columns, slices `'2012':`
- `_transform_data()` — `.T` then `expand_dims(axis=-1)`, produces shape `(features, samples, 1)`

### Common Pitfalls (from RESEARCH.md)

- Electricity CSV needs `sep=';'`, `decimal=','`, 10000+ rows (for `iloc[8920]` filtering), columns including `MT_001`
- Fractional split produces 0-length slices for datasets with <17 samples — use 100+ row fixtures
- Existing `electricity_csv_file` fixture in test_modules_forecasting.py already handles Electricity format
