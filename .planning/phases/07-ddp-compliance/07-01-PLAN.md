  <behavior>
    **build_cache_key** (per D-03):
    - Input: dataset_name="ETTm1", params={"seq_len": 128, "mode": "UNIVARIATE", "data_scaling_method": "MINMAX", "data_scaling_range": [0, 1]}
    - Output: String matching pattern `^[0-9a-f]{8}_ETTm1_.*\.cache$`
    - Deterministic: same inputs always produce same key
    - Sorted params: key is invariant to param dict ordering

    **resolve_cache_dir** (per D-02):
    - Input: cache_dir=None, dataset_name="ETTm1" → Path.home()/.cache/tsdatasets/ETTm1 (resolved absolute)
    - Input: cache_dir=custom_path, dataset_name="ETTm1" → custom_path (resolved absolute, expanded user)

    **atomic_save_npz** (per D-04):
    - Input: path to .npz file, **arrays (numpy ndarrays)
    - Output: Valid .npz file; tmp file (.tmp suffix) does NOT exist after completion
    - Round-trip: np.load() returns arrays with same shape and dtype

    **atomic_save_metadata** (per D-04):
    - Input: path to .json file, dict with schema per D-08
    - Output: Valid JSON file; tmp file does NOT exist after completion
    - Round-trip: json.load() returns same dict

    **load_metadata** (per D-07):
    - Input: path to existing .json with version=1 → returns dict
    - Input: path to existing .json with version != 1 → raises ValueError with "Cache version" message
    - Input: path to non-existent .json → raises FileNotFoundError

    **save_scaler / load_scaler** (per D-06):
    - Input: MinMaxScaler instance fitted on data, path to .pt file
    - Output: Saved scaler produces identical transform() after load
    - Uses torch.save with pickle_protocol=5, torch.load with weights_only=False

    **DatetimeIndex round-trip** (verified in tests):
    - pd.DatetimeIndex serialized as int64 nanoseconds → reconstructed identically
    - Preserves timezone-naive timestamps

    **CACHE_SCHEMA_VERSION constant**:
    - Module exports CACHE_SCHEMA_VERSION: int = 1
