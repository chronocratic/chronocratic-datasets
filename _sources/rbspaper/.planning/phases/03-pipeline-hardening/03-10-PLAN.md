    ```python
    state_path = run_dir / STATE_FILENAME

    if force:
        # --force: reset state even if it exists
        if state_path.exists():
            logger.info('Force flag set: resetting existing state')
        builder = _PipelineStateBuilder(config_hash=config_hash or config.artifacts.run_name[:8])
        # Write empty state to mark fresh start
        save_pipeline_state(state=builder.build(), path=state_path)
    elif previous_state is not None:
        # Resume mode: copy existing completed steps
        builder = _PipelineStateBuilder(config_hash=previous_state.config_hash)
        for step, tasks in previous_state.completed.items():
            for t in tasks:
                builder.mark_complete(step=step, task_name=t)
            if not tasks:
                builder.mark_complete(step=step)
        logger.info(
            'Resuming from checkpoint: %s steps complete',
            list(previous_state.completed.keys()),
        )
    else:
        # Fresh start: no state file, no previous_state
        builder = _PipelineStateBuilder(config_hash=config_hash or config.artifacts.run_name[:8])
    ```

    **IMPORTANT — NO run_name string parsing:** The config_hash is passed as an explicit `config_hash` parameter (added by Plan 08 Task 1). Do NOT extract it from `config.artifacts.run_name` via split or substring. The `or config.artifacts.run_name[:8]` fallback exists only for backward compatibility when config_hash is not provided.

    The three paths are:
    1. force=True → reset, write empty state
    2. previous_state provided → resume, copy completed
    3. Neither → fresh builder, no state written yet
