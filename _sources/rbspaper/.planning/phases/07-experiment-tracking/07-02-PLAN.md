<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| runner.py -> create_loggers() | User-supplied --tracking_mode validated against enum (online/offline/disabled) |
| core.py -> pl.Trainer(loggers=...) | Logger instances cross from runner into pipeline — must not carry secrets |
| core.py -> _log_config_to_wandb() | Config data (model params, seed, attacks) crosses into W&B cloud |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-06 | Information Disclosure | `_log_config_to_wandb` config_data | mitigate | Config contains model params, seed, attack names — no PII or secrets. trainer_kwargs may contain device info but no credentials |
| T-07-07 | Tampering | `--tracking_mode` CLI arg | mitigate | argparse `choices=['online', 'offline', 'disabled']` validates input. Invalid values rejected at parse time |
| T-07-08 | Information Disclosure | SLURM_JOB_ID env var read | accept | SLURM_JOB_ID is a non-secret job identifier. Only used for boolean detection (present/absent), value never logged |
| T-07-09 | Denial of Service | Empty loggers to Trainer | mitigate | Conditional wiring: `if config.loggers:` prevents `loggers=[]` (Pitfall 3 — triggers default TensorBoardLogger) |
</threat_model>
